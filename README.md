# Control World
Um pequeno projeto e-commerce que fiz durante meus dias de curso.

Tecnologias usadas:

HTML • CSS • JSP • Java • JavaScript • MySQL

Requisitos:

- Apache NetBeans (Opcional) 
- Apache TomCat EE 
- XAMPP 
- MySQL Connector (5.1.47) 

## Banco de dados
O projeto utiliza MySQL, portanto o script para criação do banco de dados estará disponível no arquivo 'Script SQL'
